# Security Policy

## Privacy and Offline-First Guarantee

AgentGuard is architected from the ground up as an **offline-first** tool:

- **No Remote Telemetry**: AgentGuard does not collect, transmit, or store telemetry, analytical data, or codebase contents on remote servers.
- **No Cloud Services**: Code analysis, parsing, and risk detection are performed locally within your environment.
- **No API Keys or Accounts**: You do not need to provide third-party API keys or authenticate to external services.
- **Strict Network Boundary**: AgentGuard does not initiate external outbound network connections.

## Reporting a Vulnerability

If you discover a security vulnerability within AgentGuard:

1. **Do not disclose publicly**: Avoid opening public GitHub issues for security vulnerabilities.
2. **Submit a Security Advisory**: Report vulnerabilities through GitHub Private Security Advisories.
3. **Information to Include**:
   - Detailed description of the vulnerability.
   - Steps to reproduce the issue.
   - Potential impact and affected versions.
   - Suggested mitigations if known.

We aim to acknowledge reports within 48 hours and provide a timeline for remediation.
